# API Contract - Arthsetu

## Base URL
`/api/v1`

## Modules
- **Auth**: `/auth` - Authentication & token management
- **Businesses**: `/businesses` - Business profiles & configurations
- **Transactions**: `/transactions` - Financial transactions & logs
- **Imports**: `/imports` - Batch CSV/Excel data ingestion
- **Reconciliation**: `/reconciliation` - Cross-account & bank reconciliation
- **Analysis**: `/analysis` - Financial metrics, completeness, anomalies
- **Passports**: `/passports` - Financial passport generation & verification
