# Arthsetu

Financial bridge & data verification platform for businesses.

## Structure
- `frontend/`: React + TypeScript frontend application
- `backend/`: FastAPI backend with financial analysis & reconciliation engine
- `storage/`: File storage for imported batches and generated financial passports
- `sample_data/`: Demo transactions and business profile data
- `docs/`: Architecture, database schema, and API contracts
